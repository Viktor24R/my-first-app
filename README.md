# Maryana Nails — сайт манікюрного кабінету

Адаптивний односторінковий сайт-візитка українською мовою для Maryana Nails, створений на чистих HTML, CSS і JavaScript.

## Запуск

Сторонні пакети не потрібні. Відкрийте `index.html` у браузері або запустіть локальний сервер:

```bash
python3 -m http.server 8000
```

Після цього перейдіть за адресою [http://localhost:8000](http://localhost:8000).

## Структура

- `index.html` — структура та контент сторінки;
- `styles.css` — стилі й адаптивна верстка;
- `script.js` — відкриття форми запису та повідомлення про успішну заявку;
- `assets/` — локальні ресурси сайту.

> Форма працює як демонстрація на стороні браузера. Для реального надсилання заявок необхідно під'єднати сервер або сервіс обробки форм.
